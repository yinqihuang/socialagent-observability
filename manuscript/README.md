# Camera-ready manuscript

This directory contains the V3 camera-ready manuscript corresponding to the aggregate figure data in this repository.

Compile from `source/` with:

```bash
latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex
```

The human-facing descriptive results use the September 3, 2026 data snapshot and the documented completion rule. Raw participant records are excluded from this repository.
